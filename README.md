# 📚 Library Management System - C++

A console-based Library Management System built in C++ using OOPs and File Handling. This project digitizes library operations like adding books, managing students, and tracking issued books.

### ✨ Features
- Add, Search, Update & Delete Books
- Add & Manage Student Records  
- Issue & Return Books with Date Tracking
- Auto Fine Calculation on Late Return
- Data Stored Permanently using File Handling

### 🛠️ Tech Stack
- **Language:** C++
- **Concepts:** Object Oriented Programming, File Handling (fstream), Classes & Objects

### ⚙️ How to Compile & Run
```bash
g++ library.cpp -o library
./library
